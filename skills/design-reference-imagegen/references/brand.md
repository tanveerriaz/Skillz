# Brand Reference: Identity Boards and Logo Systems

Read this after choosing the brand surface. Shared rules (one system, readability, anti-generic) live in SKILL.md. Output is a brand-guidelines board image: one complete brand world in one frame.

## 1. Output Rules

- Default: one board image, `3 × 3` grid, aspect `4:3` or `16:10`, clean presentation grid with consistent gutters, minimal text, every panel visibly connected.
- Allowed layouts: `3 × 3` full system · `2 × 3` deck overview · `2 × 2` compact concept board · `1 × 3` horizontal strip · `4 × 2` contact sheet · custom on request.
- If the user provides references, match their quality and rhythm, never their content (see §9).
- Deliver the prompt used alongside the image so the board can be regenerated or extended.

## 2. Strategy First

Before generating, infer and write down:
category · audience · product function · emotional promise · cultural position · trust level · visual world · symbolic metaphor · what the brand must avoid.

Every board must answer: what the brand represents, what the core metaphor is, how the logo expresses it, how the system scales across UI / print / image / detail, and why it feels ownable.

| Category | Core ideas | Symbol logic |
|---|---|---|
| Developer tool | building, speed, precision, control | cursor, frame, bolt, scaffold, grid |
| AI assistant | delegation, intelligence, clarity | spark, orbit, signal, path, node |
| Security | protection, vigilance, boundary | shield, eye, seal, protected core |
| Gaming | chance, reward, tension, speed | dice, gem, card, signal, trophy |
| Voice AI | sound, rhythm, command, flow | waveform, mic, orb, speech path |
| Compliance | trust, order, rules | seal, badge, document, shield |
| Drones / robotics | flight, control, vision, mission | wing, owl, crosshair, path, zone |
| Luxury / editorial | taste, material, ritual, restraint | monogram, seal, paper, emboss |
| Productivity | focus, momentum, clarity | path, check, block, calendar, light |

Symbols follow meaning; never pick them at random.

## 3. Logo Standard

The mark must be simple, memorable, symbolic, scalable, balanced, tied to the brand idea, and usable as icon, wordmark, badge, UI mark, and pattern. It should look like the result of research and reduction.

Avoid: generic lightning bolts, random animals, fake luxury crests, copied famous marks, over-complicated symbols, clipart, sparkles, variants that disagree with each other.

**Concept methods** (use one, combine two at most):
1. **Monogram + meaning** — initial fused with a metaphor via negative space, cuts, folds, or geometry (K + kite/frame, S + sound wave, A + ascent).
2. **Product action** — the core verb as an abstract mark (build → frame/scaffold; protect → shield/boundary; convert → switch/arrow; speak → waveform/pulse; automate → loop/handoff).
3. **Metaphor fusion** — two ideas in one reduced form (owl + drone vision, shield + mountain, moon + waveform, cursor + bolt). Subtle and readable.
4. **Negative space** — hidden arrow, protected center, cutout initial, internal path, folded corner. Keep it crisp.
5. **Construction geometry** — circles, diagonal cuts, grids, frames, modular blocks, orbital paths, crosshairs, measured linework. One panel may show the construction.

## 4. Board Composition

A board is a curated sequence, not nine equal tiles. Rhythm: quiet → functional → emotional → technical → atmospheric → detailed. Include a large calm cover, one digital mockup, one image-led atmosphere panel, one system/construction panel, one physical or icon application, one quiet tagline.

**Default 3 × 3 panels**
1. **Logo cover** — large mark + wordmark, minimal title, strong negative space.
2. **Logo construction** — grid, geometry, or negative-space logic; why the mark exists.
3. **Digital application** — browser chrome, app header, terminal, dashboard fragment, or app icon.
4. **Brand essence** — one short tagline, large type, sparse.
5. **Color system** — swatches, strips, discs, material chips, or palette cards.
6. **Typography** — large specimen, alphabet row, or primary/secondary pairing.
7. **Physical application** — card, folder, badge, poster, label, seal, packaging, or object.
8. **Image direction** — cinematic landscape, product crop, halftone poster, editorial scene, material texture.
9. **System detail** — UI chips, input bar, command line, icon row, badge system, component strip, pattern.

**2 × 3 mini-deck panels**
1. Logo / wordmark, centered or offset, extremely minimal
2. Browser or product surface (URL bar, app frame, prompt input)
3. Command / functional panel (terminal, install command, input state, dashboard fragment)
4. Atmosphere / campaign image (halftone landscape, cinematic photo, product world)
5. Symbol / construction / badge (mark in target, seal, geometric frame)
6. Tagline / system promise — one short line, large type, quiet background

| Dark product / operator | business, growth, sales, productivity tools | black with dark red or amber, glowing UI chips, card systems, segmented flows, icon rows, progress motifs | signal, path, switch, loop, operator mark | fast, tactical, premium |
| Dark nature / calm system | strategy, travel, wellness, climate, quiet SaaS | deep green + lime, misty landscapes, image circles, soft overlays, calm page labels | path, leaf, moon, horizon, compass, portal | calm, trustworthy, focused |
| Dark security / threat intel | security, compliance monitoring, network | black/navy, shield forms, radar lines, motion traces, red/blue alert chips | shield, raptor, eye, boundary, protected core | serious, vigilant |
| Light editorial / compliance | legal, privacy, documents, trust brands | warm ivory, paper texture, small serif labels, seals, palette object, stationery, deep blue/red/gold accents | seal, shield, document, stamp, monogram | refined, institutional yet modern |
| Luxury / beauty / fashion | beauty, fashion, hospitality, premium services | ivory/stone/espresso, serif wordmark, elegant monogram, paper grain, embossing, labels, editorial crops | monogram, seal, petal, vessel, typographic mark | tasteful, adult, expensive |

## 6. Detail, Text, Tagline, Image, Mockup, Color

**Premium details** (use a few, not all): page numbers, tiny footer labels, alignment marks, construction lines, crosshair grid, thin rules, browser bars, image masks, soft shadows, low-opacity texture, halftone treatment, one highlighted word, one accent chip, one strong icon state. Detail should reward a closer look.

**Text:** brand name, one tagline, one URL, one command, 2–5 section labels, short UI chips. Never paragraphs, tiny fake body copy, menus, lorem ipsum, or dense explanations. Text must be large and sparse enough to render legibly.

**Tagline:** short and specific — "Nothing random." / "Build better." / "On guard." / "Clarity builds confidence." No corporate slogans, buzzword soup, or inspirational filler.

**Images:** cinematic mountains, dusk skies, landscapes with brand overlay, halftone clouds, CRT scenes, dark product close-ups, dramatic object crops, textured paper, moody architecture, controlled abstract systems. Avoid stock people, office photos, robot clichés, busy or unrelated scenes. Images match palette and metaphor.

**Mockups:** browser chrome, URL bar, terminal, prompt, app icon, phone corner crop, card stack, badge, seal, folder, UI chips, dashboard fragment, input bar, product label. They are identity applications, not feature demos — no full fake dashboards, glossy device piles, or busy screens.

**Color:** one dominant palette — base, primary accent, secondary accent, neutrals. Accents repeat across panels; one accent can carry the whole system. Reference-grade combinations: black + cyan + muted coral · black + red + cream + blue · forest + lime + fog · navy + white + steel · ivory + deep blue + red + gold · black + lilac + soft purple · black + amber + red · charcoal + white + pale blue. No rainbow, no purple-blue AI glow unless the brand genuinely calls for it.

## 7. Anti-Generic

Never: floating icons, startup gradients, over-designed logos, blobs, messy collage layouts, fake tiny UI, inconsistent marks, too many colors, cheap neon, stock-template boards, slide-deck look, soulless dashboards. When in doubt, make it quieter, sharper, more intentional.

## 8. Prompt Template

```
Create a brand-kit overview board for "[BRAND NAME]".
Brand strategy: category [..]; audience [..]; personality [3 traits]; core metaphor [..];
logo idea: [how the mark fuses symbol + name + category meaning; method used].
Layout: [3×3 | 2×3 | ..] grid on a [dark charcoal | light ivory] presentation canvas, strong gutters, clean alignment, refined negative space, aspect [4:3 | 16:10].
Panels: [list panels in order, e.g. logo cover; construction; digital application; tagline; color system; typography; physical application; image direction; system detail].
Visual mode: [mode]. Palette: [base, primary accent, secondary accent, neutrals — accents repeat across panels].
Typography: [primary/secondary], large, sparse, high hierarchy; no tiny fake text.
Tagline: "[short line]". Details: [2–3 premium details].
Logo: professional, symbolic, simple, ownable, repeated consistently across panels.
Style: identity-studio presentation board, cinematic, restrained, polished; no clutter, no copied real-world logos, no stock people, no purple-blue glow.
```

## 9. Using Supplied References

Extract: layout rhythm, grid, spacing, type scale, density, logo placement, amount of text, image treatment, accent logic, system behavior.
Do not copy: the logo, brand name, composition, slogan, or any unique asset. References set the quality bar, not the template.

## 10. Brand Checklist

- [ ] Strategy written before generating; metaphor explains the mark.
- [ ] Logo uses one or two concept methods and reads at icon size.
- [ ] One visual mode; one palette; accents recur on every panel.
- [ ] Panels vary in loudness; the board has rhythm, not nine equal tiles.
- [ ] Text is sparse and legible: name, tagline, a few labels, short chips.
- [ ] Mockups are identity applications, not feature demos.
- [ ] Imagery matches palette and metaphor; no stock clichés.
- [ ] No copied marks, slogans, or assets from references or real brands.
- [ ] Existing approved brand assets preserved if the brand already exists.

## 11. Example

**Good:** developer-tool brand, dark builder mode, 3 × 3: cover with a cursor-plus-frame monogram; construction grid; terminal panel with one install command; tagline "Build better."; black + cyan + coral swatches; monospace/grotesk pairing; enamel badge; halftone mountain at dusk; UI chip strip. One accent repeats everywhere.

**Bad:** a collage of luxury mockups with unreadable labels, three different logo variants, a rainbow gradient, and paragraphs of fake body copy.
